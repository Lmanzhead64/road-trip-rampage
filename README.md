# Road Trip Rampage 🎮
A 2D RPG side-scrolling shooter. American Weekend Vacation theme.
Built with HTML5 Canvas + JavaScript for ENGR5513-21.

## How to Play
- Open index.html in any browser
- WASD to move, auto-aim & auto-fire
- Q for bombs, collect drops, beat bosses
- Upgrade in the shop between levels

## Features
- Auto-aim combat with 5 weapon types
- Upgrade shop with kill credits
- Boss fights every level
- Save progress (localStorage)
- High scores with 3-character initials
